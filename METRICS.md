# Metrics

## North Star Metric

Completed audits per week.

This directly measures user value and lead generation effectiveness.

---

## Input Metrics

1. Landing page conversion rate
2. Audit completion rate
3. Shareable report clicks

---

## Instrumentation

- Audit submissions
- PDF exports
- Email captures
- Share link opens

---

## Pivot Trigger

If audit completion drops below 15% after 1000 visitors, onboarding and UX should be redesigned.
